# 배포 연습 페이지

GitHub Pages, Netlify, Cloudflare Pages 배포를 연습하기 위한 예제 사이트입니다.
배포한 주소로 열면 어느 플랫폼에서 열렸는지, 파일이 빠짐없이 올라갔는지 표시등으로 보여줍니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| index.html | 첫 화면 |
| style.css | 디자인 |
| script.js | 플랫폼 확인, 배포 점검 |
| images/logo.svg | 로고 (이미지 경로 확인용) |
| pages/second.html | 하위 폴더 페이지 (상대 경로 확인용) |
| 404.html | 없는 주소로 들어왔을 때 보이는 화면 |

## 연습 순서

1. 폴더 구조를 그대로 유지해서 올립니다.
2. 받은 주소로 접속해 표시등이 모두 초록인지 확인합니다.
3. index.html의 `v1`을 `v2`로 바꿔 다시 배포하고, 버전 표시가 바뀌는지 확인합니다.
4. 주소 끝에 `/없는주소`를 붙여 404 화면이 나오는지 확인합니다.
